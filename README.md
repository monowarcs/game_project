# Game Arcade

A complete, 100% static browser game arcade built with HTML5, CSS3, and Vanilla JavaScript. 

## Features

- **20 Playable Games**: From classics like Snake and Pong to mini RPGs and survival games.
- **Responsive Design**: Works on desktop, tablet, and mobile.
- **Mobile Touch Controls**: Virtual D-pad and Action buttons automatically appear on touch devices or small screens.
- **Local Storage**: Automatically saves your High Scores, Favorite Games, and play statistics across sessions.
- **No Backend**: This project is fully static. There are no databases, no server-side logic, and no build steps required.

## Technologies Used

- HTML5
- CSS3 (Vanilla, CSS Variables, Flexbox/Grid)
- JavaScript (ES6+, Classes, Canvas API)
- `localStorage` for data persistence.

## GitHub Pages Deployment

This project is specifically designed to be easily deployed to GitHub Pages without any configuration.

1. Create a new repository on your GitHub account.
2. Upload all the files from this directory to the repository.
3. Go to the repository **Settings**.
4. Scroll down (or look in the sidebar) for **Pages**.
5. Under "Build and deployment", set the **Source** to `Deploy from a branch`.
6. Set the **Branch** to `main` (or `master`) and folder to `/ (root)`.
7. Click **Save**.
8. Within a few minutes, your Game Arcade will be live at `https://[YOUR_USERNAME].github.io/[YOUR_REPOSITORY_NAME]/`.

No absolute paths are used, ensuring all assets load correctly regardless of the sub-path.
